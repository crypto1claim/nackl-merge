# NACKL MERGE — передача проекта / как продолжать

Документ для владельца и будущих разработчиков (в т.ч. AI-сессий). Описывает,
что это, как устроено, как деплоить, что уже сделано, что осталось, и как
следить за игрой дальше.

---

## 1. Что это

Suika-style merge-игра в экосистеме **Acki Nacki**, запускается как **Telegram
Mini App** на мобильных. Пока игрок сливает монеты, подключённый кошелёк
**майнит** (через Bee Engine SDK) — за вклад в верификацию блоков сеть начисляет
**NACKL**. Внутриигровая валюта — **MRG** (за слияния, тратится в магазине на темы
и скины монет). **MRG в NACKL не конвертируется** — это разные вещи.

- **Прод:** https://nackl-merge.vercel.app
- **Репозиторий:** github.com/crypto1claim/nackl-merge (ветка `main`)
- **Кошелёк-получатель / dApp:** `cryptoclaim`, dApp id `0x…018`
- **Стек:** React 18 + TypeScript + Vite + matter.js (физика) + @teamgosh/bee-sdk (майнинг)

## 3. Как запускать и деплоить

```bash
npm install
npm run dev      # локально (http://localhost:5173)
npm run build    # прод-сборка: tsc && vite build — ДОЛЖНА проходить без ошибок
npm run preview  # посмотреть прод-сборку локально
```

**Деплой полностью автоматический:** любой `git push` в `main` → Vercel сам
собирает и публикует на `nackl-merge.vercel.app`. Отдельных команд деплоя нет.

⚠️ **Vercel блокирует деплой при ЛЮБОЙ TypeScript-ошибке** (`tsc` в build).
Всегда проверяй `npm run build` локально перед пушем.

## 4. Как продолжать разработку

1. Склонируй репозиторий заново (рабочая копия в `/tmp/...` — временная, могла
   быть удалена): `git clone https://github.com/crypto1claim/nackl-merge`.
2. Внеси изменения, `npm run build` для проверки.
3. `git push` в `main` → проверь в дашборде Vercel, что сборка стала **Ready**.
4. Открой прод **в Telegram** (не в десктоп-браузере) и проверь на реальном
   телефоне — особенно подключение кошелька и плавность тем на слабых iPhone.

**С AI-ассистентом (Claude Code / Cursor / и т.п.):** открой новую сессию в папке
репозитория и дай контекст — «это NACKL MERGE, прод на Vercel из main, читай
HANDOFF.md». Ассистент подтянет этот файл и сможет продолжить.

## 5. Как следить за игрой (мониторинг)

- **Vercel Dashboard** — статус сборок, логи, аналитика трафика/ошибок фронта.
- **Telegram BotFather / настройки Mini App** — точка входа игроков.
- **Acki Nacki эксплорер** — активность майнинга кошелька.
- **Vercel Analytics** — подключена (см. раздел 6a). После включения в дашборде
  показывает воронку и краши.

## 5a. Аналитика — что включить (ОДИН клик, сделать обязательно)

Код аналитики уже встроен (Vercel Web Analytics). Чтобы данные начали
собираться, нужно один раз включить её в дашборде:

1. Vercel → проект **nackl-merge** → вкладка **Analytics** → кнопка **Enable**.
2. Через пару часов после трафика данные появятся там же.

Собираются события (вкладка Analytics → Events):
- `app_open` — открытий игры
- `onboarding_have_wallet` / `onboarding_need_wallet` — выбор на 1-м экране
- `wallet_connect_start` / `_success` / `_fail` / `wallet_engine_load_fail` — воронка коннекта
- `game_start` / `game_over` (с заработком) — игровая активность
- `theme_purchase` — покупки тем
- `app_error` — краши (с местом и текстом ошибки)

Так ты увидишь, где отваливаются игроки (например, много `wallet_connect_start`,
но мало `_success` = проблема с подключением) и какие краши реально происходят.

⚠️ На бесплатном тарифе Vercel у событий есть месячный лимит — при большом
трафике он исчерпается. Тогда либо апгрейд тарифа, либо смена провайдера: весь
код аналитики в одном файле `src/analytics.ts`, провайдер меняется только там.

## 6. Что уже сделано (последняя сессия подготовки к запуску)

- Убрана чит-кнопка «+1 000 000 MRG» из настроек (дыра в экономике).
- GPU-оптимизация тяжёлых тем (Океан/China/Halloween/Christmas) для iPhone 14.
- Сезонные темы Halloween/Christmas **скрыты** (флаг `hidden` в `themes.ts` —
  убрать перед праздником, чтобы вернуть в продажу).
- Первый запуск на **английском**, переключатель языка на онбординге.
- Убрано ложное обещание «конвертации MRG → NACKL».
- **ErrorBoundary** + глобальные обработчики `error`/`unhandledrejection`
  (вместо белого экрана — экран с кнопкой перезагрузки).
- **Защита игрового цикла** (try/catch + finally — кадр-сбой не морозит канвас)
  и слияния (try/catch в микрозадаче).
- **Лоадер WASM** (7.7 МБ) с прогрессом и ретраем при сбое сети.
- i18n на пути коннекта (англ. юзер больше не видит русские строки).
- **FRUITS-кэш** — устранена пересборка массива монет на каждый кадр (лаги).
- Рекорд партии больше не перезаписывается бонусами (daily/достижения).
- `spendMRG` защищён от отрицательных сумм; `checkGameOver` игнорирует слитые
  монеты (нет ложного game over во время взрывов).
- Подключена **аналитика** (Vercel Web Analytics, `src/analytics.ts`): воронка
  коннекта, game_start/over, покупки, краши. Нужно включить в дашборде — см. 5a.
- **Стабильность движка (2-й аудит):** добавлен `epoch`-guard на все отложенные
  коллбэки детонаций/слияний (Restart/Exit во время взрыва больше не начисляет
  очки в новую партию — закрыт эксплойт фарма); защита от двойной детонации
  Shake; pointer-листенеры снимаются в `stop()` (не копятся между партиями);
  убрана зависимость `wallet.address` (движок не пересоздаётся зря); фикс гонки
  devicemotion-permission; `miner.free()` перед пересозданием (нет утечки WASM).
- **Комфорт игры:** поле имени кошелька 16px (нет авто-зума iOS при фокусе);
  вспышка Shake Damage приглушена (не заливает весь экран); русские строки в
  магазине (вкладка/подсказка/кнопка бустеров) переведены через `t()`.
- **Надёжность подключения кошелька (3-й аудит):** AN Wallet на iOS открывался
  по диплинку, но не показывал окно подтверждения. Добавлены фолбэки: кнопка
  «Открыть AN Wallet» — настоящий `<a>` (надёжнее для universal links), кнопка
  «Скопировать ссылку», QR-код диплинка (штатный путь по докам Acki Nacki —
  сканер внутри AN Wallet); кнопка «← Ввести другое имя». Ключи незавершённой
  авторизации персистятся (`acki_merge_bee_pending_<имя>`) — перезагрузка на
  этапе подтверждения больше не ломает подключение. **Майнер восстанавливается
  после перезагрузки страницы** (`resumeWallet()` при старте App) — раньше
  майнинг после любого релоада молча не работал. Новые события аналитики:
  `wallet_resume_fail`, `wallet_link_copied`, `wallet_qr_shown`.

**Безопасность:** `npm audit` — 0 уязвимостей в проде; нет `eval`/`innerHTML`/XSS.
Секреты майнера хранятся в localStorage (модель Bee SDK, клиентская) — реальная
ценность (NACKL) живёт on-chain, накрутка локального MRG влияет только на покупку
игровых тем.

## 7. Что осталось — приоритеты

**🔴 Высокий**
1. **Включить Vercel Analytics** в дашборде (см. раздел 5a) — код уже встроен,
   нужен один клик. Без этого события не собираются.
2. **Ручной прогон на реальном iPhone 14** перед массовым трафиком (коннект
   кошелька end-to-end + плавность каждой темы).

**🟠 Средний — осталось (требует проверки на устройстве / продуктовых решений)**
3. **Daily bonus — эксплойт перевода часов.** Игрок может перевести системное
   время вперёд и фармить ежедневный бонус (`dailyBonus.ts`). Надёжный фикс
   только серверный (любой клиентский time-guard ломает легитимный кейс «23:59 →
   00:01»). Урон низкий: MRG — косметика, не NACKL. Чинить вместе с бэкендом.
4. `engine.ts`: анимации фона (god-rays, декор) «замерзают» при idle-skip —
   решить, нужны ли живыми (тогда отдельный слой) или это осознанная статика.
5. **Тач-зоны HUD-кнопок** (бустеры/Shake/Pause) 30–36px при рекомендованных
   ≥44px — на мелких экранах легко промахнуться. Увеличить аккуратно (HUD
   чувствителен к «прыжкам» по высоте — проверять на устройстве).
6. **Дроп монеты по тапу:** одиночный тап мгновенно роняет монету в точке
   касания — случайные тапы фрустрируют. Рассмотреть «дроп только после
   перемещения». Меняет ощущение управления — тестировать на телефоне.

**🟢 Низкий**
7. `@keyframes fog-drift` в теме Halloween не определён — туман статичен (тема
   сейчас скрыта; поправить перед открытием к празднику).
8. Несколько `title=`-тултипов остались на русском (на мобиле не видны).
9. Нет landscape-лейаута (Telegram не лочит поворот) — в горизонтали банка
   узкая. Либо залочить portrait, либо дать landscape-стили.

## 8. Важные подводные камни

- **Bee SDK эндпоинт ОБЯЗАН быть `https://mainnet.ackinacki.org`** (со схемой
  `https://`). Без неё SDK идёт на мёртвый `http://...:8600` → коннект ломается.
- **dApp id `0x…018`** — менять нельзя (подтверждён сетью).
- **Сброс прогресса** делается через смену версии флага в `src/bootstrap.ts`
  (`acki_merge_full_reset_vN` → vN+1). Срабатывает один раз на устройство.
- **Кэш `index.html`** — `must-revalidate` (в `vercel.json`), ассеты — immutable.
  Не ломай это, иначе вернутся stale-версии у игроков.
